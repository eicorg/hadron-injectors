# EIC accelerator lattices

This repository contains working lattice models for the AGS and Booster rings.

- `ags-lattice/` contains the canonical AGS MAD-X snapshot, cleaned MAD-X tree, and BMAD translation.
- `booster/` contains the canonical Booster MAD-X snapshot, cleaned MAD-X tree, and BMAD translation.

The `source/` and top-level legacy files are preserved snapshots. Generated
Tao/MAD-X output and digested caches are excluded from version control where
possible. Each lattice directory contains its own provenance and validation
notes.
